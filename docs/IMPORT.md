# Режим без ответа VK: импорт реальных публикаций

Импорт работает без приложения, токена и согласования VK. Он не обращается к VK, не ищет публикации и не проверяет наличие аудио. Администратор загружает только реальные данные из собственной разрешённой выгрузки и подтверждает корректность сведений. Без файла рейтинг остаётся пустым. Демонстрационные показатели в production не создаются.

## Как пользоваться

1. Войдите в `/admin` с ADMIN_PASSWORD.
2. В блоке «Импорт реальных публикаций» скачайте пустой CSV-шаблон.
3. Заполните его реальными данными, сохраните в UTF-8. Разделитель — точка с запятой; поддерживается также CSV с запятой и кавычками.
4. Укажите название источника, выберите файл и нажмите «Проверить файл». Этот шаг ничего не сохраняет.
5. Проверьте число строк, уникальных постов, треков, диапазон дат и первые пять записей. Подтвердите право использовать файл и нажмите «Импортировать в рейтинг».
6. Откройте главную страницу. Выберите период, в который попадают даты файла. Импорт старых постов не создаст публикаций за текущие 24 часа.

## Формат

```csv
исполнитель;трек;дата;ссылка;автор;репост
```

Каждая строка описывает один трек в одном посте:

- `исполнитель`: непустое имя, до 300 символов.
- `трек`: непустое название, до 500 символов.
- `дата`: фактическое время публикации в ISO 8601 с часовым поясом, формат `YYYY-MM-DDTHH:mm:ss+03:00` или с `Z`. Будущие и невозможные даты отклоняются. Не заменяйте дату поста датой загрузки файла.
- `ссылка`: HTTPS-ссылка вида `https://vk.com/wall<owner_id>_<post_id>` либо аналогичная на vk.ru. Короткие ссылки и ссылки на профили не подходят. Ссылки не открываются сервером, параметры отслеживания удаляются.
- `автор`: фактический числовой ID автора поста; отрицательный для сообщества. Не указывайте ID исполнителя вместо автора публикации.
- `репост`: `1` / `0`, `да` / `нет` либо `true` / `false`.

Поддерживаются также английские заголовки: `artist,title,published_at,url,author_id,is_repost`. Названия могут включать запятые и кавычки при корректном CSV-экранировании. Лимит одного файла: 2 МБ и 5000 записей.

## Правила подсчёта

Один пост и один трек учитываются один раз. Повторный импорт того же файла не увеличивает счётчики. Пост с несколькими треками можно описать несколькими строками; сводка постов считает его один раз. Дата, автор и признак репоста у этих строк обязаны совпадать. Импорт транзакционный: противоречие с ранее сохранёнными сведениями отменяет весь файл.

Треки из CSV получают отдельные идентификаторы на основе нормализованных имени исполнителя и названия. Разные версии с одинаковой парой объединятся. Автоматического распознавания музыки нет. В API используется идентификатор аудиозаписи. Источники автоматически не объединяются; если пост уже получен официальным API, его CSV-импорт отклоняется. Позднее API может заменить импортированные связи поста своим наблюдением. Старые снимки сохраняют исходную идентичность.

На главной странице и в CSV-экспорте указан источник данных и ограниченный охват. Наличие корректной ссылки не доказывает существование поста или наличие музыки: это сведения администратора. «Новые хиты» и проценты роста отражают только имеющуюся историю; неполная выгрузка может влиять на результат.

## Ежедневные снимки

`vercel.json` задаёт вызов `/api/cron` в 00:10 UTC (03:10 Москва) ежедневно. Для Vercel задайте отдельный CRON_SECRET от 32 символов; планировщик передаёт его в Authorization Bearer. После redeploy проверьте расписание и журнал в Vercel: локальная проверка не подтверждает фактическое выполнение расписания на хостинге.

Без настроенного VK endpoint только пересчитывает и сохраняет снимки уже загруженных данных, не создавая новых публикаций и не меняя дату последнего импорта. С настроенными VK_ACCESS_TOKEN и VK_WALL_IDS он запускает официальный сбор. CLI-альтернатива: `npm run daily`. Сохраняются позиции за 24 часа, 7 и 30 дней; новые исходные данные появляются только после очередного импорта или успешного API-сбора.

## API администратора

- `GET /api/admin/import/template`: пустой шаблон; требуется сессия.
- `POST /api/admin/import`: JSON `{csv, source, preview: true}` — проверка без записи.
- `POST /api/admin/import`: JSON `{csv, source, confirmed: true}` — транзакционный импорт.

POST требует административную сессию и корректный Origin. Ответы не кэшируются. Нет публичного импорта и загрузки файлов по URL. CSV-экспорт защищает поля от интерпретации как формул электронных таблиц.
